# PrezPoint

**macOS pointer overlay for presentations and demos.**

PrezPoint draws a full-screen overlay above all your windows, making your cursor visible and your point obvious — without moving or minimising anything underneath.

## Features

- **Spotlight** — dims the screen with an illuminated circle around the cursor
- **Laser Pointer** — glowing dot with motion trail
- **Loupe Magnifier** — real-time 2× zoom lens
- **Blur / Privacy Mask** — frosted overlay for sensitive content
- **Row & Column Focus** — reading guides for spreadsheets
- **Freehand Drawing** — annotate on screen, clear with ⌘⌫

## Requirements

macOS 13 Ventura or later · Apple Silicon and Intel
